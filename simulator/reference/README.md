# Machine reference for the simulator

Drop anything that shows the real PikPak here; the 3D scene is modelled from it.

Most useful, in order:

1. A CAD export of the cell: `.glb` / `.gltf` (best), `.step` or `.stl`.
2. Photos: whole machine from the front, the side and above; the arm and
   gripper close up; the crate position relative to the infeed belt.
3. Key dimensions in mm: belt width and height, arm reach, crate internal
   size(s), tray size(s).
4. Real figures: typical pick-and-place cycle time, crate change time,
   belt speed, products per pick.

Anything customer-confidential should stay out of git: say so and the file
gets added to `.gitignore`.
